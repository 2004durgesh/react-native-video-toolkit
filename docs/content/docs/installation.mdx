## Requirements

<Callout type="info">
  React Native Video Toolkit works with new architecture (Fabric + TurboModules) enabled projects. Ensure you're using
  React Native 0.76 or higher.
</Callout>

The toolkit is built on [react-native-video v7](https://docs.thewidlarzgroup.com/react-native-video/docs/v7/fundamentals/intro), which is currently in beta:

- **react-native-video** `7.0.0-beta.11` and **react-native-nitro-modules** `0.35.0` or higher
- **iOS** 15.0+ and **Android** 6.0+
- **Apple TV (tvOS) is not supported yet.** The v7 beta's iOS pod only declares iOS.

<Callout type="warn">
  Coming from a toolkit version built on react-native-video v6? See [Migrating to react-native-video
  v7](/docs/migration-v7) for the breaking changes.
</Callout>

## Installation Steps

<Steps>

<Step>

### Install Dependencies

Install the main library along with all required peer dependencies:

```npm
npm install react-native-video-toolkit react-native-video@7.0.0-beta.11 react-native-nitro-modules react-native-gesture-handler react-native-reanimated react-native-worklets react-native-svg react-native-orientation-director
```

<Callout type="warning">
  Make sure to install all dependencies as they are required for the library to function properly. Pin
  `react-native-video` to an exact v7 beta: betas can include breaking changes.
</Callout>

<Callout type="info">
**Targeting web?** react-native-video v7 plays video on web through video.js. `7.0.0-beta.11` declares
`@videojs/react@^10.0.0-beta.11`, which also allows the stable 10.x release, and that release is not compatible.
Pin it to the beta in your root `package.json`:

```json
{
  "resolutions": { "@videojs/react": "10.0.0-beta.11" }
}
```

With npm, use `"overrides"` instead of `"resolutions"`. Without the pin, the player fails on web with _"Element
type is invalid … Check the render method of `VideoView`"_.

</Callout>

</Step>

<Step>

### Configure React Native Reanimated

Add the Reanimated babel plugin to your `babel.config.js`:

```js
module.exports = {
  presets: ['module:@react-native/babel-preset'],
  plugins: [
    'react-native-reanimated/plugin', // This should be the last plugin
  ],
};
```

<Callout type="info">The Reanimated plugin must be listed last in the plugins array.</Callout>

<Callout type="info">
  On Reanimated 4+, use `react-native-worklets/plugin` instead of `react-native-reanimated/plugin`.
</Callout>

</Step>

<Step>

### Configure React Native Gesture Handler

Add the gesture handler configuration to your `index.js`, `App.js` , `_layout.tsx` or equivalent entry file:

```tsx
import { GestureHandlerRootView } from 'react-native-gesture-handler';

const App = () => <GestureHandlerRootView style={{ flex: 1 }}>{/* Your app content */}</GestureHandlerRootView>;
```

</Step>

<Step>

### Wrap Your App

Wrap your app with the required providers:

```tsx
import React from 'react';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { VideoProvider } from 'react-native-video-toolkit';

export default function App() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <VideoProvider>{/* Your app content */}</VideoProvider>
    </GestureHandlerRootView>
  );
}
```

</Step>

<Step>
### Update app.json for screen orientation
If you're using Expo, add the following to your `app.json` or `app.config.js` to include the necessary plugin:

```json
{
  "expo": {
    "plugins": ["react-native-orientation-director"]
  }
}
```

<Callout type="info">
  For bare React Native projects, follow the setup instructions in the
  [react-native-orientation-director](https://github.com/gladiuscode/react-native-orientation-director?tab=readme-ov-file#bare)
</Callout>

</Step>

<Step>
### Configure react-native-video
If you're using Expo, add the react-native-video config plugin to your `app.json` or `app.config.js`. All options are optional:

```json
{
  "expo": {
    "plugins": [
      [
        "react-native-video",
        {
          "enableBackgroundAudio": false,
          "enableAndroidPictureInPicture": false,
          "androidExtensions": {
            "useExoplayerHls": true,
            "useExoplayerDash": true
          }
        }
      ]
    ]
  }
}
```

| Option                          | Default | Description                                                               |
| ------------------------------- | ------- | ------------------------------------------------------------------------- |
| `enableBackgroundAudio`         | `false` | Configures the app so audio can keep playing in the background.           |
| `enableAndroidPictureInPicture` | `false` | Adds the Android manifest settings needed for picture-in-picture.         |
| `androidExtensions`             | both on | Which ExoPlayer extensions to include. Turn off HLS or DASH to save size. |

<Callout type="info">
  The v6 plugin options `enableNotificationControls`, `useExoplayerRtsp` and `useExoplayerSmoothStreaming` no longer
  exist. Notification controls are always configured and are turned on at runtime with the player's
  `showNotificationControls` property.
</Callout>

<Callout type="info">
For bare React Native projects, follow the setup instructions in the [react-native-video v7 docs](https://docs.thewidlarzgroup.com/react-native-video/docs/v7/fundamentals/configuration/without-expo)
</Callout>
</Step>

<Step>

### Install iOS Dependencies (iOS only)

Install the native pods (the module is autolinked under the New Architecture):

```bash
cd ios && pod install
```

<Callout type="info">
  Fullscreen on iOS hides the status bar. For this to take effect, your app's `Info.plist` must have
  `UIViewControllerBasedStatusBarAppearance` set to `false`. Expo prebuild and the default React Native template usually
  set this already — add it manually only if the status bar doesn't hide in fullscreen.
</Callout>

For Expo, set it in `app.json`:

```json
{
  "expo": {
    "ios": {
      "infoPlist": {
        "UIViewControllerBasedStatusBarAppearance": false
      }
    }
  }
}
```

For bare React Native, add it to `ios/<YourApp>/Info.plist`:

```xml
<key>UIViewControllerBasedStatusBarAppearance</key>
<false/>
```

</Step>

<Step>

### Clean and Rebuild

For Expo managed workflow, prebuild your app.

```bash
npx expo prebuild
```

After all this is done, clean your project and rebuild.

```bash
# For Android
cd android && ./gradlew clean && cd ..
npx react-native run-android

# For iOS
cd ios && xcodebuild clean && cd ..
npx react-native run-ios
```

</Step>

</Steps>

## Verification

To verify your installation is working correctly, try importing and using the VideoPlayer component:

```tsx
import { VideoPlayer, DefaultLayout } from 'react-native-video-toolkit';

export default function TestVideo() {
  return (
    <VideoPlayer
      source={{ uri: 'https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8' }}
      style={{ width: '100%', height: 200 }}>
      <DefaultLayout />
    </VideoPlayer>
  );
}
```

## Troubleshooting

### Common Issues

**Metro bundler errors after installation:**

- Clear Metro cache: `npx react-native start --reset-cache`
- Clear node modules: `rm -rf node_modules && npm install`

**Android build errors:**

- Ensure you have the latest Android build tools
- Try cleaning the Android build: `cd android && ./gradlew clean`

**Gesture handler not working:**

- Make sure you've imported `react-native-gesture-handler` at the top of your entry file
- Verify that `GestureHandlerRootView` wraps your entire app

**"Failed to get NitroModules: The native "NitroModules" Turbo/Native-Module could not be found":**

- react-native-video v7 and `react-native-nitro-modules` contain native code, so a JavaScript reload is not enough.
  Rebuild the app, and run `pod install` first on iOS.

**Web: "Element type is invalid … Check the render method of `VideoView`":**

- `@videojs/react` resolved to an incompatible stable release. Pin it to `10.0.0-beta.11` as shown in
  [Install Dependencies](#install-dependencies).
