# VideoPlayer

The `VideoPlayer` is the **root component** of the toolkit.  
It provides video playback, gesture handling, and a flexible API for composing custom control layouts.

This component uses a **compound component pattern**:

```tsx
<VideoPlayer>
  <VideoPlayer.Controls>
    <VideoPlayer.PlayButton />
    <VideoPlayer.ProgressBar />
    <VideoPlayer.TimeDisplay />
  </VideoPlayer.Controls>
</VideoPlayer>
```

---

## Usage

```tsx
import { VideoPlayer } from 'react-native-video-toolkit';

export default function App() {
  return (
    <VideoPlayer source={{ uri: 'https://example.com/video.mp4' }} viewProps={{ resizeMode: 'contain' }}>
      <VideoPlayer.Controls>
        <VideoPlayer.PlayButton />
        <VideoPlayer.ProgressBar />
        <VideoPlayer.TimeDisplay />
        <VideoPlayer.VolumeControl />
        <VideoPlayer.FullscreenButton />
        <VideoPlayer.SettingsButton />
      </VideoPlayer.Controls>
    </VideoPlayer>
  );
}
```

## Props

| Prop                | Type                                                           | Required | Default | Description                                                                                                                                                                                                                                                     |
| ------------------- | -------------------------------------------------------------- | -------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `source`            | `VideoConfig \| VideoSource`                                   | Yes      | –       | A URL, a `require()`d asset, or a react-native-video [`VideoConfig`](https://docs.thewidlarzgroup.com/react-native-video/docs/v7/player/video-player) (`uri`, `headers`, `drm`, `externalSubtitles`, `bufferConfig`...). `require()` sources don't work on web. |
| `children`          | `ReactNode`                                                    | No       | –       | Optional custom overlay or controls.                                                                                                                                                                                                                            |
| `containerStyle`    | `StyleProp<ViewStyle>`                                         | No       | –       | Style applied to the root container.                                                                                                                                                                                                                            |
| `viewProps`         | `Partial<Omit<VideoViewProps, 'player'>>`                      | No       | –       | Props passed to react-native-video's [`VideoView`](https://docs.thewidlarzgroup.com/react-native-video/docs/v7/video-view/props), e.g. `resizeMode`, `pictureInPicture`, `surfaceType`.                                                                         |
| `events`            | `Partial<AllPlayerEvents>`                                     | No       | –       | Player event callbacks (`onLoad`, `onProgress`, `onEnd`, `onError`, ...). They run after the toolkit's own handling. See [player events](https://docs.thewidlarzgroup.com/react-native-video/docs/v7/player/events).                                            |
| `gestureProps`      | [`GestureHandlerProps`](../types/gestures#gesturehandlerprops) | No       | –       | Props for the built-in `GestureHandler` (e.g. double-tap to seek).                                                                                                                                                                                              |
| `videoStyle`        | `StyleProp<ViewStyle>`                                         | No       | –       | Style applied to the [video](./core/video-surface.mdx) component.                                                                                                                                                                                               |
| `customAudioTracks` | `AudioTrack[]`                                                 | No       | –       | Custom audio tracks to use when `config.useCustomAudioTracks` is `true`. Web only, see [Track support](#track-support).                                                                                                                                         |
| `customVideoTracks` | `CustomVideoTrack[]`                                           | No       | –       | Custom video tracks to use when `config.useCustomVideoTracks` is `true`. Web only. See [CustomVideoTrack](../types/video#customvideotrack).                                                                                                                     |

<Callout type="info">
  `VideoConfig`, `VideoSource`, `VideoViewProps`, `AllPlayerEvents` and the track types are exported by
  `react-native-video`.
</Callout>

## Track support

Track selection depends on what react-native-video v7 supports on each platform:

| Track                | iOS / Android | Web                                 |
| -------------------- | ------------- | ----------------------------------- |
| Subtitles / captions | ✅            | ✅                                  |
| Audio tracks         | ❌            | ✅ (Safari; experimental elsewhere) |
| Video quality        | ❌            | ✅ (Safari; experimental elsewhere) |

Where audio or quality selection isn't supported, the toolkit leaves those track lists empty and the settings menu
hides the **Audio** and **Video** entries.

## Examples

### Minimal Player

```tsx
<VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
  <DefaultLayout />
</VideoPlayer>
```

### With Custom Controls

```tsx
<VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
  <VideoPlayer.Controls style={{ justifyContent: 'space-between' }}>
    <VideoPlayer.PlayButton />
    <VideoPlayer.ProgressBar />
    <VideoPlayer.TimeDisplay />
  </VideoPlayer.Controls>
</VideoPlayer>
```

### With Subtitles

Pass subtitle files in the source's `externalSubtitles`. They appear in the settings menu and the
[SubtitleToggleButton](./controls/subtitle-toggle-button), and the first one is turned on by default.

```tsx
<VideoPlayer
  source={{
    uri: 'https://example.com/video.mp4',
    externalSubtitles: [
      { uri: 'https://example.com/subs/en.vtt', label: 'English', language: 'en', type: 'vtt' },
      { uri: 'https://example.com/subs/es.vtt', label: 'Español', language: 'es', type: 'vtt' },
    ],
  }}>
  <DefaultLayout />
</VideoPlayer>
```

Supported `type` values are `vtt`, `srt`, `ssa`, `ass` and `auto`. If the URL ends with the file extension you can
leave `type` out.

### Listening to Player Events

```tsx
<VideoPlayer
  source={{ uri: 'https://example.com/video.mp4' }}
  events={{
    onLoad: (data) => console.log('duration', data.duration),
    onEnd: () => console.log('finished'),
    onError: (error) => console.warn(error.code, error.message),
  }}>
  <DefaultLayout />
</VideoPlayer>
```

### With Custom Tracks

Custom tracks replace the lists the player reports. Like the built-in lists, they are only used on web.

```tsx
import type { AudioTrack } from 'react-native-video';
import type { CustomVideoTrack } from 'react-native-video-toolkit';

const audioTracks: AudioTrack[] = [
  { id: 'en', label: 'English', language: 'en', selected: true },
  { id: 'es', label: 'Spanish', language: 'es', selected: false },
];

// CustomVideoTrack: `label` is shown in the menu; `height` is only used to build a label like "720p".
const videoTracks: CustomVideoTrack[] = [
  { id: 'auto', label: 'Auto' },
  { id: '1080', label: '1080p Full HD' },
  { id: '720', height: 720 },
];

<VideoProvider config={{ useCustomAudioTracks: true, useCustomVideoTracks: true }}>
  <VideoPlayer
    source={{ uri: 'https://example.com/video.m3u8' }}
    customAudioTracks={audioTracks}
    customVideoTracks={videoTracks}>
    <DefaultLayout />
  </VideoPlayer>
</VideoProvider>;
```

<Callout type="info">
  On web, selecting a custom track asks the player to select the track with the same `id`, so the ids must match the
  tracks the player reports.
</Callout>

## Compound Components

The `VideoPlayer` exports several prebuilt UI primitives:

| Component                          | Description                                         |
| ---------------------------------- | --------------------------------------------------- |
| `VideoPlayer.Controls`             | A container for grouping controls (`absoluteFill`). |
| `VideoPlayer.PlayButton`           | Toggles play/pause.                                 |
| `VideoPlayer.ProgressBar`          | Displays seekable progress.                         |
| `VideoPlayer.TimeDisplay`          | Shows current time / duration.                      |
| `VideoPlayer.VolumeControl`        | Slider for adjusting volume.                        |
| `VideoPlayer.FullscreenButton`     | Toggles fullscreen.                                 |
| `VideoPlayer.MuteButton`           | Toggles mute on/off.                                |
| `VideoPlayer.LoadingSpinner`       | Spinner for buffering state.                        |
| `VideoPlayer.SettingsButton`       | Opens the settings menu.                            |
| `VideoPlayer.SubtitleToggleButton` | Turns subtitles on and off.                         |

---

<Callout type="info">
  - The **layout automatically adapts** when toggling fullscreen (height/width swap based on device orientation). - All
  controls are theme-aware (colors, sizes come from `useVideo` provider). - If you don't like the built-in controls, you
  can **compose your own** using the hooks and providers.
</Callout>
