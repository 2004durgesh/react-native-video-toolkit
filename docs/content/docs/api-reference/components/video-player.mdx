# VideoPlayer

The `VideoPlayer` is the **root component** of the toolkit.  
It provides video playback, gesture handling, and a flexible API for composing custom control layouts.

This component uses a **compound component pattern**:

```tsx
<VideoPlayer>
  <VideoPlayer.Controls>
    <VideoPlayer.PlayButton />
    <VideoPlayer.ProgressBar />
    <VideoPlayer.TimeDisplay />
  </VideoPlayer.Controls>
</VideoPlayer>
```

---

## Usage

`VideoPlayer` needs a `VideoProvider` above it. Most apps put one at their root, as shown in [Installation](/docs/installation).

```tsx
import { VideoPlayer, VideoProvider } from 'react-native-video-toolkit';

export default function App() {
  return (
    <VideoProvider>
      <VideoPlayer source={{ uri: 'https://example.com/video.mp4' }} videoProps={{ resizeMode: 'contain' }}>
        <VideoPlayer.Controls>
          <VideoPlayer.PlayButton />
          <VideoPlayer.ProgressBar />
          <VideoPlayer.TimeDisplay />
          <VideoPlayer.VolumeControl />
          <VideoPlayer.FullscreenButton />
        </VideoPlayer.Controls>
      </VideoPlayer>
    </VideoProvider>
  );
}
```

## Props

| Prop                | Type                                                           | Required | Default | Description                                                                                                                                                                                                                                |
| ------------------- | -------------------------------------------------------------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `source`            | `ReactVideoProps['source']`                                    | Yes      | –       | Video source (`uri`, local file, or require). Uses the source type from `react-native-video`.                                                                                                                                              |
| `children`          | `ReactNode`                                                    | No       | –       | Optional custom overlay or controls.                                                                                                                                                                                                       |
| `containerStyle`    | `StyleProp<ViewStyle>`                                         | No       | –       | Style applied to the root container.                                                                                                                                                                                                       |
| `videoProps`        | `ReactVideoProps`                                              | No       | –       | Props passed to the underlying [`react-native-video`](https://github.com/react-native-video/react-native-video) player.                                                                                                                    |
| `gestureProps`      | [`GestureHandlerProps`](../types/gestures#gesturehandlerprops) | No       | –       | Props for the built-in `GestureHandler` (e.g. double-tap to seek).                                                                                                                                                                         |
| `videoStyle`        | `StyleProp<ViewStyle>`                                         | No       | –       | Style applied to the [video](./core/video-surface.mdx) component.                                                                                                                                                                          |
| `customAudioTracks` | `AudioTrack[]`                                                 | No       | –       | Audio tracks to list instead of the source's own. Passing them turns custom audio tracks on.                                                                                                                                               |
| `customVideoTracks` | `CustomVideoTrack[]`                                           | No       | –       | Qualities to list instead of the source's own, with labels. Passing them turns custom video tracks on, and the settings menu shows the list as it is, without its own Auto entry. See [CustomVideoTrack](../types/video#customvideotrack). |
| `testID`            | `string`                                                       | No       | `video` | Identifies the player in end-to-end tests. Its parts' IDs start with it, so give each player on a screen its own. See [Testing](/docs/testing).                                                                                            |
| `...props`          | `ViewProps`                                                    | No       | –       | Other `View` props go to the player's outer view.                                                                                                                                                                                          |

## Examples

The examples below assume a `VideoProvider` above the player.

### Minimal Player

```tsx
<VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
  <DefaultLayout />
</VideoPlayer>
```

### With Custom Controls

```tsx
<VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
  <VideoPlayer.Controls style={{ justifyContent: 'space-between' }}>
    <VideoPlayer.PlayButton />
    <VideoPlayer.ProgressBar />
    <VideoPlayer.TimeDisplay />
  </VideoPlayer.Controls>
</VideoPlayer>
```

### With Custom Tracks

```tsx
import type { AudioTrack } from 'react-native-video';
import type { CustomVideoTrack } from 'react-native-video-toolkit';

const audioTracks: AudioTrack[] = [
  { index: 0, title: 'English', language: 'en', type: 'audio/mp4a-latm' },
  { index: 1, title: 'Spanish', language: 'es', type: 'audio/mp4a-latm' },
];

// CustomVideoTrack provides a user-friendly API with label and optional uri
const videoTracks: CustomVideoTrack[] = [
  { height: 0, label: 'Auto' },
  { height: 1080, label: '1080p Full HD' },
  { height: 720, label: '720p HD' },
  { height: 480, label: '480p SD' },
];

<VideoPlayer
  source={{ uri: 'https://example.com/video.m3u8' }}
  customAudioTracks={audioTracks}
  customVideoTracks={videoTracks}>
  <DefaultLayout />
</VideoPlayer>;
```

## Compound Components

The `VideoPlayer` exports several prebuilt UI primitives:

| Component                            | Description                                                                                                                                                                                                                                                             |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VideoPlayer.Controls`               | A container for grouping controls (`absoluteFill`).                                                                                                                                                                                                                     |
| `VideoPlayer.PlayButton`             | Toggles play/pause.                                                                                                                                                                                                                                                     |
| `VideoPlayer.ProgressBar`            | Displays seekable progress.                                                                                                                                                                                                                                             |
| `VideoPlayer.TimeDisplay`            | Shows current time / duration.                                                                                                                                                                                                                                          |
| `VideoPlayer.VolumeControl`          | Slider for adjusting volume.                                                                                                                                                                                                                                            |
| `VideoPlayer.FullscreenButton`       | Toggles fullscreen.                                                                                                                                                                                                                                                     |
| `VideoPlayer.MuteButton`             | Toggles mute on/off.                                                                                                                                                                                                                                                    |
| `VideoPlayer.LoadingSpinner`         | Spinner for buffering state.                                                                                                                                                                                                                                            |
| `VideoPlayer.SettingsButton`         | Opens settings menu.                                                                                                                                                                                                                                                    |
| `VideoPlayer.SubtitleToggleButton`   | Toggles subtitles on and off. Renders nothing when the source has no subtitles.                                                                                                                                                                                         |
| `VideoPlayer.PictureInPictureButton` | Enters and exits picture-in-picture. Renders nothing where picture-in-picture isn't supported.                                                                                                                                                                          |
| `VideoPlayer.UpNext`                 | A card that counts down to the next source once the current one ends, with "Cancel" and "Play now". Render it after the layout.                                                                                                                                         |
| `VideoPlayer.Overlay`                | A full-size layer over the video for your own content, which can fade with the controls and tint the video. Render it after the layout.                                                                                                                                 |
| `VideoPlayer.Captions`               | The subtitles the toolkit draws. `VideoPlayer` draws them in every layout; render this in your layout to place them yourself or pass `controlsInset`, `centerControlsInset`, `style` or `textStyle`, and it replaces the player's own. See [Subtitles](../../captions). |

---

<Callout type="info">

- The **layout automatically adapts** when toggling fullscreen (height/width swap based on device orientation).
- All controls are theme-aware: their colors and sizes come from the theme on `VideoProvider`.
- If you don't like the built-in controls, you can **compose your own** using the hooks and providers.

</Callout>
