## Props

| Prop   | Type        | Required | Description                                                                                                                         |
| ------ | ----------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `text` | `string`    | Yes      | The string to display.                                                                                                              |
| `...`  | `TextProps` | No       | In addition to `text`, this component accepts all other props from the React Native `Text` component, like `style`, `onPress`, etc. |

---

<Callout type="info">
**When to Use**

- Use `Subtitle` for **secondary information** under a `Title`, such as:
  - Episode numbers
  - Season numbers/series titles
  - Short descriptions or hints

</Callout>
