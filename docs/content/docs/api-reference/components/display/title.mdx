---
title: 'Title'
description: A themed text component for displaying headings, labels, or titles inside the video player UI.
---

## Usage

```tsx
import { Title } from 'react-native-video-toolkit';

export function Example() {
  return <Title text="Playback Settings" />;
}
```

---

## Props

| Prop    | Type                   | Required | Default | Description                                              |
| ------- | ---------------------- | -------- | ------- | -------------------------------------------------------- |
| `text`  | `string`               | Yes      | –       | The string to display.                                   |
| `style` | `StyleProp<TextStyle>` | No       | –       | Optional override styles (merged with theme + defaults). |

---

## Notes

<Callout type="info">
**When to Use**

- Use `Title` for **primary headings** or **main labels** within the video player UI, such as:
  - Video titles

</Callout>
