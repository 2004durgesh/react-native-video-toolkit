## API Reference

### `Menu.Root`

Wraps all menu components and manages the navigation stack.

| Prop          | Type     | Default  | Required | Description                    |
| ------------- | -------- | -------- | -------- | ------------------------------ |
| `initialView` | `string` | `"root"` | No       | The first viewId in the stack. |

---

### `Menu.Trigger`

Button that opens the menu.

| Prop       | Type                  | Required | Description                           |
| ---------- | --------------------- | -------- | ------------------------------------- |
| `...props` | `SettingsButtonProps` | No       | Props passed to the `SettingsButton`. |

---

### `Menu.Header`

Header for the menu, with back/close buttons and a title.

| Prop              | Type                   | Default | Required | Description                                 |
| ----------------- | ---------------------- | ------- | -------- | ------------------------------------------- |
| `title`           | `string`               | –       | No       | Title of the current view.                  |
| `showBackButton`  | `boolean`              | `true`  | No       | Show the back button.                       |
| `showCloseButton` | `boolean`              | `true`  | No       | Show the close button.                      |
| `style`           | `StyleProp<ViewStyle>` | –       | No       | Custom style for the header container.      |
| `titleStyle`      | `StyleProp<TextStyle>` | –       | No       | Custom style for the title text.            |
| `children`        | `ReactNode`            | -       | No       | Custom content to render inside the header. |
| `...props`        | `ViewProps`            | –       | No       | Additional props for the header container.  |

---

### `Menu.Content`

The `BottomSheet` wrapper for menu views.

| Prop       | Type                                 | Default | Required | Description                                       |
| ---------- | ------------------------------------ | ------- | -------- | ------------------------------------------------- |
| `children` | `ReactNode`                          |         | Yes      | Nested `Menu.SubContent` blocks.                  |
| `header`   | `(currentView: string) => ReactNode` |         | No       | Optional custom header renderer.                  |
| `...props` | `BottomSheetProps`                   | -       | No       | All other props from the `BottomSheet` component. |

---

### `Menu.SubContent`

Renders content for a specific `viewId`.
Only visible when `currentView` matches.

| Prop       | Type                   | Required | Description                           |
| ---------- | ---------------------- | -------- | ------------------------------------- |
| `viewId`   | `string`               | Yes      | ID to match against navigation stack. |
| `children` | `ReactNode`            | Yes      | Sub-menu items.                       |
| `style`    | `StyleProp<ViewStyle>` | No       | Custom style for the content view.    |

---

### `Menu.Item`

Basic clickable row. Can either close the menu or navigate to a sub-view.

| Prop         | Type                       | Default | Required | Description                                                             |
| ------------ | -------------------------- | ------- | -------- | ----------------------------------------------------------------------- |
| `onPress`    | `(value?: string) => void` | –       | No       | Action when pressed.                                                    |
| `navigateTo` | `string`                   | –       | No       | If set, navigates to this sub-view.                                     |
| `autoClose`  | `boolean`                  | `true`  | No       | If true, closes menu after press (ignored if `navigateTo` is provided). |
| `disabled`   | `boolean`                  | `false` | No       | Disables interaction.                                                   |
| `value`      | `string`                   | –       | No       | Optional value passed to `onPress`.                                     |
| `style`      | `StyleProp<ViewStyle>`     | –       | No       | Custom style for the item container.                                    |
| `textStyle`  | `StyleProp<TextStyle>`     | –       | No       | Custom style for the item text (if children is a string).               |
| `children`   | `ReactNode`                | Yes     | –        | The content of the item.                                                |

---

### `Menu.Label`

Non-interactive label for section headers.

| Prop       | Type                   | Required | Description                                             |
| ---------- | ---------------------- | -------- | ------------------------------------------------------- |
| `children` | `ReactNode`            | Yes      | The label text.                                         |
| `style`    | `StyleProp<TextStyle>` | No       | Custom style for the text.                              |
| `...props` | `TextProps`            | No       | All other props from the React Native `Text` component. |

---

### `Menu.Separator`

Divider line between items.

| Prop       | Type                   | Required | Description                                             |
| ---------- | ---------------------- | -------- | ------------------------------------------------------- |
| `style`    | `StyleProp<ViewStyle>` | No       | Custom style for the line.                              |
| `...props` | `ViewProps`            | No       | All other props from the React Native `View` component. |

---

### `Menu.Group`

Simple wrapper for grouping related items.

| Prop       | Type                   | Required | Description                                             |
| ---------- | ---------------------- | -------- | ------------------------------------------------------- |
| `children` | `ReactNode`            | Yes      | The items to group.                                     |
| `style`    | `StyleProp<ViewStyle>` | No       | Custom style for the group container.                   |
| `...props` | `ViewProps`            | No       | All other props from the React Native `View` component. |

---

### `Menu.CheckboxItem`

Toggleable option with a check indicator.

| Prop              | Type                         | Default | Required | Description                                                   |
| ----------------- | ---------------------------- | ------- | -------- | ------------------------------------------------------------- |
| `checked`         | `boolean`                    |         | No       | Controlled checked state.                                     |
| `onCheckedChange` | `(checked: boolean) => void` |         | No       | Called when toggled.                                          |
| `...props`        | `MenuItemProps`              | -       | No       | All other props from the `Menu.Item` component are supported. |

If `checked` is not provided, it manages its own state.

---

### `Menu.Close`

Button that closes the menu manually.

| Prop       | Type                   | Required | Description                                                  |
| ---------- | ---------------------- | -------- | ------------------------------------------------------------ |
| `style`    | `StyleProp<ViewStyle>` | No       | Custom style for the button.                                 |
| `...props` | `PressableProps`       | No       | All other props from the React Native `Pressable` component. |

---

### `Menu.Back`

Button that navigates back in the menu stack.

| Prop       | Type                   | Required | Description                                                  |
| ---------- | ---------------------- | -------- | ------------------------------------------------------------ |
| `style`    | `StyleProp<ViewStyle>` | No       | Custom style for the button.                                 |
| `...props` | `PressableProps`       | No       | All other props from the React Native `Pressable` component. |

---

## Styling

- Colors, background, and borders adapt automatically to `theme` from `useVideo()`.
- Animations are handled by `react-native-reanimated`.
- You can pass `style` and `textStyle` props to most components for customization.
