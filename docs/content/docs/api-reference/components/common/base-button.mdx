### Props

| Prop       | Type              | Default    | Description                               |
| ---------- | ----------------- | ---------- | ----------------------------------------- |
| `children` | `React.ReactNode` | `required` | The content to render inside the button.  |
| `onTap`    | `() => void`      | `required` | Callback fired when the button is tapped. |
