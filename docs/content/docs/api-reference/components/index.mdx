## Quick Start

The main entry point is the `VideoPlayer` component, inside a `VideoProvider`. `DefaultLayout` gives it the standard controls:

```tsx
import { DefaultLayout, VideoPlayer, VideoProvider } from 'react-native-video-toolkit';

function BasicPlayer() {
  return (
    <VideoProvider>
      <VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
        <DefaultLayout />
      </VideoPlayer>
    </VideoProvider>
  );
}
```

To style the player's outer view, pass [`containerStyle`](/docs/api-reference/components/video-player#props).

## Component Architecture

The library follows a compound component pattern where the `VideoPlayer` serves as the main container, and all other components can be composed within it:

- **VideoPlayer**: Main container: plays the video, and handles gestures and subtitles
- **DefaultLayout**: The ready-made controls: title, play button, progress bar, settings menu and more
- **VideoPlayer.Controls**: An empty full-size container for the controls of a layout you build yourself
- **Individual Controls**: Granular control components
- **Display Elements**: Visual feedback components
- **Layout Components**: Structural containers

<Callout type="warn">
  Render `VideoPlayer` and the other components inside a `VideoProvider`. `VideoPlayer` doesn't provide one itself.
</Callout>
