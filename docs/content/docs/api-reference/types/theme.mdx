---
title: 'Theme Types'
description: Types related to theming including color schemes, font sizes, icon sizes, and animation durations.
---

### `colors`

| Property              | Type     | Required | Description                                    |
| --------------------- | -------- | -------- | ---------------------------------------------- |
| `textMain`            | `string` | Yes      | Primary text color.                            |
| `textSecondary`       | `string` | Yes      | Secondary text color.                          |
| `iconNormal`          | `string` | Yes      | Default icon color.                            |
| `iconActive`          | `string` | Yes      | Active icon state (e.g., CC turned on).        |
| `sliderTrackActive`   | `string` | Yes      | Filled part of sliders (Progress/Volume).      |
| `sliderTrackInactive` | `string` | Yes      | Unfilled part of sliders.                      |
| `sliderTrackCache`    | `string` | Yes      | Buffered/loaded track color.                   |
| `sliderThumb`         | `string` | Yes      | Draggable knob color.                          |
| `menuBackground`      | `string` | Yes      | Popover sheet background color.                |
| `menuBorder`          | `string` | Yes      | Popover outline color.                         |
| `menuText`            | `string` | Yes      | Text color inside the menu.                    |
| `menuSeparator`       | `string` | Yes      | Divider line color in the menu.                |
| `badgeBackground`     | `string` | Yes      | Background for speed/seek badges (e.g., "2x"). |
| `ripple`              | `string` | Yes      | Ripple effect color for buttons.               |
| `spinner`             | `string` | Yes      | Loading indicator color.                       |
| `error`               | `string` | Yes      | Color for error states.                        |
| `success`             | `string` | Yes      | Color for success states.                      |

### `iconSizes`

| Property | Type     | Required | Default | Description   |
| -------- | -------- | -------- | ------- | ------------- |
| `sm`     | `number` | Yes      | –       | Small icons.  |
| `md`     | `number` | Yes      | –       | Medium icons. |
| `lg`     | `number` | Yes      | –       | Large icons.  |

### `fontSizes`

| Property | Type     | Required | Default | Description       |
| -------- | -------- | -------- | ------- | ----------------- |
| `sm`     | `number` | Yes      | –       | Small text size.  |
| `md`     | `number` | Yes      | –       | Medium text size. |
| `lg`     | `number` | Yes      | –       | Large text size.  |

### `animations`

| Property | Type     | Required | Default | Description                        |
| -------- | -------- | -------- | ------- | ---------------------------------- |
| `fast`   | `number` | Yes      | `100`   | Fast animation duration (100ms).   |
| `normal` | `number` | Yes      | `200`   | Normal animation duration (200ms). |
| `slow`   | `number` | Yes      | `300`   | Slow animation duration (300ms).   |
