## `useSettings()`

A hook for managing video settings such as videoTrack, audio tracks, and subtitle tracks, and controlling the visibility of a settings menu.

### Usage

```tsx
import { useSettings } from 'react-native-video-toolkit';

export const MyComponent = () => {
  const { isSettingsMenuVisible, toggleSettingsMenu } = useSettings();
  // ...
};
```

### Returns

| Value                     | Type                                                              | Description                                                          |
| ------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------- |
| `videoTrack`              | `CustomVideoTrack \| VideoTrack \| null`                          | The current video quality setting.                                   |
| `videoTracks`             | `(CustomVideoTrack \| VideoTrack)[]`                              | The list of available video qualities.                               |
| `setVideoTrack`           | `(newVideoTrack: CustomVideoTrack \| VideoTrack \| null) => void` | A function to set the current video quality.                         |
| `setAvailableVideoTracks` | `(videoTracks: (CustomVideoTrack \| VideoTrack)[]) => void`       | A function to set the list of available video qualities.             |
| `audioTrack`              | `AudioTrack \| null`                                              | The current audio track setting.                                     |
| `audioTracks`             | `AudioTrack[]`                                                    | The list of available audio tracks.                                  |
| `setAudioTrack`           | `(newAudioTrack: AudioTrack \| null) => void`                     | A function to set the current audio track.                           |
| `setAvailableAudioTracks` | `(audioTracks: AudioTrack[]) => void`                             | A function to set the list of available audio tracks.                |
| `textTrack`               | `TextTrack \| null`                                               | The current subtitle track setting.                                  |
| `textTracks`              | `TextTrack[]`                                                     | The list of available subtitle tracks.                               |
| `setTextTrack`            | `(newTextTrack: TextTrack \| null) => void`                       | A function to set the current subtitle track.                        |
| `setAvailableTextTracks`  | `(textTracks: TextTrack[]) => void`                               | A function to set the list of available subtitle tracks.             |
| `isSettingsMenuVisible`   | `boolean`                                                         | A boolean indicating whether the settings menu is currently visible. |
| `openSettings`            | `() => void`                                                      | A function to explicitly open the settings menu.                     |
| `closeSettings`           | `() => void`                                                      | A function to explicitly close the settings menu.                    |
| `toggleSettingsMenu`      | `() => void`                                                      | A function to toggle the visibility of the settings menu.            |
