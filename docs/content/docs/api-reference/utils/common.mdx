## `combineHandlers`

A utility function that combines multiple event handlers into a single function. It's particularly useful when you want to attach multiple callbacks to a single event without creating a new function inline.

<Callout type="info">
  You can use `combineHandlers` to merge your custom `onPress` handler with the one provided by a component. This is
  useful when you want to extend the functionality of a component without losing its original behavior.
</Callout>

### Usage

```tsx
import { combineHandlers } from 'react-native-video-toolkit';

const handleClick = combineHandlers(
  () => {},
  () => {}
);
```

### Parameters

| Parameter  | Type                           | Required | Default | Description                            |
| ---------- | ------------------------------ | -------- | ------- | -------------------------------------- |
| `handlers` | `((...args: any[]) => void)[]` | Yes      | –       | An array of event handlers to combine. |

### Returns

| Type                       | Description                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------- |
| `(...args: any[]) => void` | A single function that calls all the provided handlers in the order they were passed. |

### Example

```tsx
import { combineHandlers } from 'react-native-video-toolkit';

const onClick1 = () => console.log('click1');
const onClick2 = () => console.log('click2');

const handleClick = combineHandlers(onClick1, onClick2);
```

## `dedupeVideoTracks`

Deduplicates video (quality) tracks by `label`, keeping the first track for each label. react-native-video v7 doesn't
report resolution or bitrate per track, so the label is the only thing to compare.

### Usage

```tsx
import { dedupeVideoTracks } from 'react-native-video-toolkit';

const videoTracks = [
  { id: '0', label: '720p', selected: true },
  { id: '1', label: '720p', selected: false },
  { id: '2', label: '1080p', selected: false },
];

const dedupedTracks = dedupeVideoTracks(videoTracks); // 720p (id 0), 1080p
```

### Parameters

| Parameter | Type           | Required | Description                |
| --------- | -------------- | -------- | -------------------------- |
| `tracks`  | `VideoTrack[]` | Yes      | The array of video tracks. |

### Returns

| Type           | Description                               |
| -------------- | ----------------------------------------- |
| `VideoTrack[]` | The tracks with duplicate labels removed. |

## `dedupeLanguageTracks`

Deduplicates audio or text tracks by `language` and `label`, keeping the first track for each combination. Tracks
without a language are kept, since external subtitles may omit it.

### Usage

```tsx
import { dedupeLanguageTracks } from 'react-native-video-toolkit';

const audioTracks = [
  { id: '0', language: 'en', label: 'English Stereo', selected: true },
  { id: '1', language: 'en', label: 'English Stereo', selected: false },
  { id: '2', language: 'en', label: 'English 5.1', selected: false },
  { id: '3', language: 'fr', label: 'Français', selected: false },
];

const dedupedTracks = dedupeLanguageTracks(audioTracks); // English Stereo, English 5.1, Français
```

### Parameters

| Parameter | Type                          | Required | Description                        |
| --------- | ----------------------------- | -------- | ---------------------------------- |
| `tracks`  | `(AudioTrack \| TextTrack)[]` | Yes      | The array of audio or text tracks. |

### Returns

| Type                          | Description                                                 |
| ----------------------------- | ----------------------------------------------------------- |
| `(AudioTrack \| TextTrack)[]` | The tracks with duplicate language and label pairs removed. |

## `hexToRgba`

A utility function that converts a hex color to an rgba color.

### Usage

```tsx
import { hexToRgba } from 'react-native-video-toolkit';

const rgbaColor = hexToRgba('#FF0000', 0.5);
```

### Parameters

| Parameter | Type     | Required | Default | Description               |
| --------- | -------- | -------- | ------- | ------------------------- |
| `hex`     | `string` | Yes      | –       | The hex color to convert. |
| `alpha`   | `number` | Yes      | –       | The alpha value to apply. |

### Returns

| Type     | Description            |
| -------- | ---------------------- |
| `string` | The rgba color string. |

### Example

```tsx
import { hexToRgba } from 'react-native-video-toolkit';

const rgbaColor = hexToRgba('#FF0000', 0.5);
// rgbaColor will be 'rgba(255, 0, 0, 0.5)'
```
