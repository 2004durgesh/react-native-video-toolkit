title: ThemeProvider
description: Read the player's theme in your own components with useTheme.

import { Callout } from 'fumadocs-ui/components/callout';

Pass your theme to `VideoProvider`'s `theme` prop. To read it in your own components, call `useTheme()` anywhere below the provider.

```tsx
import { VideoProvider, useTheme } from 'react-native-video-toolkit';
import { Text } from 'react-native';

const Caption = ({ text }: { text: string }) => {
  const theme = useTheme();
  return <Text style={{ color: theme.colors.textMain, fontSize: theme.fontSizes.sm }}>{text}</Text>;
};

export const App = () => (
  <VideoProvider theme={{ colors: { textMain: '#FFEB3B' } }}>
    <Caption text="Episode 5" />
  </VideoProvider>
);
```

## useTheme

Returns the theme of the nearest `VideoProvider`, with every key you left out filled in from the default theme.

### Returns

| Value   | Type    | Description         |
| :------ | :------ | :------------------ |
| `theme` | `Theme` | The player's theme. |

## ThemeProvider

<Callout type="warning">
  Deprecated. The toolkit's controls read the theme from `VideoProvider`, so `ThemeProvider` only changes what
  `useTheme()` returns below it. Pass the theme to `VideoProvider` instead. `ThemeProvider` will be removed in 2.0.
</Callout>

| Prop       | Type        | Default    | Description             |
| :--------- | :---------- | :--------- | :---------------------- |
| `theme`    | `Theme`     | `required` | The theme object.       |
| `children` | `ReactNode` | `required` | The children to render. |
