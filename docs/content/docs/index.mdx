## Features

- 🎮 **Gesture Controls**: Built-in gesture handling for tap, double-tap, pinch, and swipe
- 🎨 **Customizable UI**: Fully customizable components with theming support
- ⚡ **Modern Architecture**: Built for React Native 0.76+ with Fabric and TurboModules
- 🏗️ **Compound Components**: Flexible component composition pattern
- 🎯 **TypeScript**: Full TypeScript support with comprehensive type definitions
- 📱 **Cross-Platform**: Works on both iOS and Android

## Quick Example

```tsx
import { VideoPlayer } from 'react-native-video-toolkit';

function MyVideoPlayer() {
  return (
    <VideoPlayer source={{ uri: 'https://example.com/video.mp4' }} style={{ width: '100%', height: 200 }}>
      <VideoPlayer.Controls />
    </VideoPlayer>
  );
}
```
