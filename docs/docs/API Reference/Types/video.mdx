# Video Types

This document outlines the types related to the video player.

## `VideoSource`

The `VideoSource` interface defines the source of the video to be played. Extends the source prop from `react-native-video` to include all the properties available in source prop of `react-native-video`.

```typescript
export interface VideoSource {
  uri: string;
  type?: string;
  headers?: Record<string, string>;
}
```

:::note
The `uri` is the only required property. The `type` and `headers` are optional and can be used to provide more information about the video source.
:::

## `VideoState`

The `VideoState` interface represents the current state of the video player.

```typescript
export interface VideoState {
  isPlaying: boolean;
  currentTime: number;
  duration: number;
  buffering: boolean;
  muted: boolean;
  volume: number;
  playbackRate: number;
  fullscreen: boolean;
  error: string | null;
}
```

## `VideoPlayerConfig`

The `VideoPlayerConfig` interface allows you to configure the behavior of the video player.

| Property                  | Type         | Description                                                                 | Default                  |
| ------------------------- | ------------ | --------------------------------------------------------------------------- | ------------------------ |
| `autoHideControls`        | `boolean`    | If `true`, the controls will automatically hide after a certain delay.      | `true`                   |
| `autoPlay`                | `boolean`    | If `true`, the video will start playing automatically.                      | `true`                   |
| `autoHideDelay`           | `number`     | The delay in milliseconds before the controls are hidden.                   | `5000`                   |
| `enableDoubleTapGestures` | `boolean`    | If `true`, the user can double-tap to seek forward or backward.             | `true`                   |
| `enableFullscreen`        | `boolean`    | If `true`, the user can enter and exit fullscreen mode.                     | `true`                   |
| `enableVolumeControl`     | `boolean`    | If `true`, the user can control the volume of the video.                    | `true`                   |
| `enablePanGestures`       | `boolean`    | If `true`, the user can use pan gestures to control volume and brightness.  | `true`                   |
| `enableScreenRotation`    | `boolean`    | If `true`, the screen will rotate automatically when the device is rotated. | `true`                   |
| `playbackRates`           | `number[]`   | An array of playback rates to be displayed in the settings menu.            | `[0.5, 1, 1.25, 1.5, 2]` |
| `onEnterFullscreen`       | `() => void` | A callback function that is called when the player enters fullscreen mode.  | `undefined`              |
| `onExitFullscreen`        | `() => void` | A callback function that is called when the player exits fullscreen mode.   | `undefined`              |
| `onHideControls`          | `() => void` | A callback function that is called when the controls are hidden.            | `undefined`              |
| `onShowControls`          | `() => void` | A callback function that is called when the controls are shown.             | `undefined`              |
