# Layouts

Pre-built layouts to quickly set up a video player UI.

## `DefaultLayout`

A comprehensive layout with standard controls.

### Usage

```tsx
import { VideoPlayer, DefaultLayout } from 'react-native-video-toolkit';

<VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
  <DefaultLayout />
</VideoPlayer>;
```

## `MinimalLayout`

A minimalist layout with essential controls.

### Usage

```tsx
import { VideoPlayer, MinimalLayout } from 'react-native-video-toolkit';

<VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
  <MinimalLayout />
</VideoPlayer>;
```
