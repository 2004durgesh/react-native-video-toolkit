# DefaultLayout

`DefaultLayout` is a pre-built layout that provides a standard, modern video player interface. It includes a comprehensive set of controls suitable for most use cases.

## Usage

```tsx
import { VideoPlayer, DefaultLayout } from 'react-native-video-toolkit';

const MyVideoPlayer = () => {
  return (
    <VideoPlayer source={{ uri: 'https://example.com/video.mp4' }}>
      <DefaultLayout title="My Video" subtitle="An example video" />
    </VideoPlayer>
  );
};
```

---

## Props

| Prop       | Type     | Required | Default | Description                  |
| ---------- | -------- | -------- | ------- | ---------------------------- |
| `title`    | `string` | No       | –       | The title of the video.      |
| `subtitle` | `string` | No       | –       | The subtitle or description. |

---

## Example

### Basic Usage

This example shows how to use `DefaultLayout` to create a fully-featured video player.

```tsx
import React from 'react';
import { View, StyleSheet } from 'react-native';
import { VideoPlayer, DefaultLayout } from 'react-native-video-toolkit';

export default function App() {
  return (
    <View style={styles.container}>
      <VideoPlayer
        source={{
          uri: 'http://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4',
        }}>
        <DefaultLayout title="Big Buck Bunny" subtitle="A classic short film" />
      </VideoPlayer>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```
