# MuteButton

`MuteButton` is a control component that toggles the **muted state** of the video.  
It switches between mute and unmute icons automatically and can be customized in **size**, **color**, and **style**.  
Custom icons can also be provided via `renderMuteIcon` and `renderUnmuteIcon`.

---

## Usage

```tsx
import { MuteButton } from 'react-native-media-toolkit';

const MyMuteButton = () => {
  return <MuteButton />;
};
```

---

## Props

| Prop               | Type                    | Required | Default          | Description                                  |
| ------------------ | ----------------------- | -------- | ---------------- | -------------------------------------------- |
| `size`             | `number`                | No       | –                | Size of the icon button.                     |
| `color`            | `string`                | No       | Theme text color | Color of the icon.                           |
| `style`            | `StyleProp<ViewStyle>`  | No       | –                | Custom styles for the mute button container. |
| `renderMuteIcon`   | `() => React.ReactNode` | No       | `<VolumeX />`    | Custom render function for the mute icon.    |
| `renderUnmuteIcon` | `() => React.ReactNode` | No       | `<Volume2 />`    | Custom render function for the unmute icon.  |

---

## Examples

### Default MuteButton

```tsx
<MuteButton />
```

### Customized Icon Size & Color

```tsx
<MuteButton size={32} color="red" />
```

### With Custom Icons

```tsx
import { Bell, BellOff } from 'lucide-react-native';

<MuteButton renderMuteIcon={() => <BellOff />} renderUnmuteIcon={() => <Bell />} />;
```

---

## Integration Example

Place inside your `VideoPlayer` layout:

```tsx
import { VideoPlayer, MuteButton } from 'react-native-media-toolkit';

const MyVideoPlayer = () => {
  return (
    <VideoPlayer source={videoSource}>
      <Controls>
        <MuteButton size={28} color="white" />
      </Controls>
    </VideoPlayer>
  );
};
```

:::info

- The mute state is fully managed internally by the `useVolume` hook.
- You can override the icons for a fully customized experience.
- Works seamlessly with gesture handling via `muteTapGesture`.

:::
