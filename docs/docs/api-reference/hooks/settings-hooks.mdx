# Settings Hooks

### `useSettings()`

A hook for managing video settings such as videoTrack, audio tracks, and subtitle tracks, and controlling the visibility of a settings menu.

#### Returns

`useSettings` returns an object with the following properties:

- `videoTrack`: The current video quality setting (`VideoTrack | null`).
- `videoTracks`: The list of available video qualities (`VideoTrack[]`).
- `setVideoTrack`: A function `(newVideoTrack: VideoTrack | null) => void` to set the video quality.
- `getVideoTracks`: A function `(videoTracks: VideoTrack[]) => void` to get the available video qualities.
- `audioTrack`: The current audio track setting (`AudioTrack | null`).
- `audioTracks`: The list of available audio tracks (`AudioTrack[]`).
- `setAudioTrack`: A function `(newAudioTrack: AudioTrack | null) => void` to set the audio track.
- `getAudioTracks`: A function `(audioTracks: AudioTrack[]) => void` to get the available audio tracks.
- `textTrack`: The current subtitle track setting (`TextTrack | null`).
- `textTracks`: The list of available subtitle tracks (`TextTrack[]`).
- `setTextTrack`: A function `(newTextTrack: TextTrack | null) => void` to set the subtitle track.
- `getTextTracks`: A function `(textTracks: TextTrack[]) => void` to get the available subtitle tracks.
- `isSettingsMenuVisible`: A boolean indicating whether the settings menu is currently visible.
- `openSettings`: A function `() => void` to explicitly open the settings menu.
- `closeSettings`: A function `() => void` to explicitly close the settings menu.
- `toggleSettingsMenu`: A function `() => void` to toggle the visibility of the settings menu.
- `settingsTapGesture`: A `Gesture.Tap()` object configured for single taps to toggle the settings menu. ExecutesThis can be used with a `GestureDetector` component.

```tsx
import { useSettings } from 'react-native-video-toolkit';
import { GestureDetector } from 'react-native-gesture-handler';

const MySettingsButton = () => {
  const { isSettingsMenuVisible, toggleSettingsMenu, settingsTapGesture, setVideoTrack, videoTracks } = useSettings();

  const handleQualityChange = () => {
    // Example: set quality to the first available track
    if (videoTracks.length > 0) {
      setVideoTrack(videoTracks[0]);
    }
  };

  return (
    <GestureDetector gesture={settingsTapGesture}>
      <GearIcon />
    </GestureDetector>
  );
};
```
